# KnowledgeBase

Проект платформы Knowledge Hub для онлайн- и офлайн-школы духовных практик.

## Документация

- [Архитектура и инфраструктура](docs/architecture.md) — текущее состояние репозитория, целевая схема MVP, параметры VPS, этапы внедрения и требования перед production.

## Текущий статус

Репозиторий содержит начальный Django-проект и Docker Compose для разработки с PostgreSQL. Wagtail, Traefik, Redis/Celery и S3-интеграция относятся к планируемой архитектуре и еще не подключены.

Перед публичным production-развертыванием требуется отдельная production-конфигурация. Подробности и рекомендуемая последовательность описаны в документе по архитектуре.
